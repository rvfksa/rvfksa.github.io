Restore Machines

Every time your machine list is saved, a backup copy is kept automatically — no need to remember to download anything. If your machine list is ever showing wrong or blank details, restore it here.

Shift & Timing

Set Day and Night shift hours — they no longer have to mirror each other — and how long after each shift ends an Operator can still log a reading or a Supervisor can still approve one before it's marked Delayed / Logged Late and locked to Admin only. Every change takes effect from a date you choose, so readings from before that date keep being judged by whatever was actually running back then, and don't get re-graded after the fact.

Add a New Rule

Readings dated on or after this date use this rule. Set it to a future date to line up a change (e.g. the first day of Ramadan) ahead of time.

Starting vs. Ending Photo Cutover

This is what decides whether a reading is automatically saved as a "Starting" or "Ending" photo, since Operators and Supervisors no longer pick it themselves. Before this clock time = Starting, from this time on = Ending. Defaults to the middle of each shift, but set it explicitly here if you ever need to.

Machine Working Hours

Separate from the Day/Night Start-End times above — those set the full shift (e.g. 6:30 to 6:30 = 12 hours, for attendance). This is the shorter number production, machine, and Total Picks efficiency math actually runs on (e.g. 11.5 hours, accounting for an untracked break). Changing the shift length above does NOT change this — set it here directly.

Grace Period — When Each Locks

For each one, choose either a number of minutes after that shift ends, or a fixed clock time.

Rule History
Machine Re-entry Cooldown

A machine an Operator or Supervisor just logged a reading for disappears from their machine list for a while — this is what stops an accidental duplicate entry on the same machine. It comes back on its own once the cooldown passes.

Weekly Automatic Stop & Machine Hours

For one day of the week (e.g. every Thursday), automatically apply a fixed cleaning stop to every running machine and reduce that day's Machine Working Hours to match — Operators still get picks for that time if the reason has a picks/hour rate set, but it isn't held against their efficiency (Machine Working Hours already accounts for it).

Add a Rule

Applies to this weekday on or after this date — earlier dates (including any you've already corrected by hand) are left exactly as they are.

Salary Cycle (Earned Picks default range)

My Status defaults its Earned Picks range to the current salary cycle instead of showing every pick ever earned — so an Operator sees exactly what counts toward their next payment, without needing to know how to use the date filter themselves. This only sets the DEFAULT dates shown; anyone can still pick a different range manually.

e.g. 26 means each cycle runs the 26th of one month through the 25th of the next.

Clean Up Old Reading Photos

Removes the PHOTO from readings in the date range below — the date, shift, reading value, diff, stop time, and everything else about the entry stays exactly as it is, permanently, for your records. Only the photo itself is deleted, to free up space once entries are old enough that nobody needs to look at the photo anymore. This cannot be undone — once a photo is deleted here, it's gone.

Calculate Production Numbers (one-time)

Pre-calculates and saves each approved reading's production number, plus a small summary per employee per day — so Report, Dashboard, My Status, and Picks can all read an already-correct result instead of recalculating your entire history every time they're opened. Run this once now to cover existing entries — going forward, every new approval, edit, or reset keeps this up to date automatically. Safe to run more than once; it only ever changes what's actually wrong or missing.

What Executive Management Can See

Controls which profile sections an Executive Management user can open when they view an employee's record from the Dashboard. This never affects what Admin or the employee themselves can see.

Who Can See Passport Location & Renewal Status

This is separate from every other permission in the app — nobody sees this section on an employee's Passport tab unless Admin puts them here, no matter what role or pages they otherwise have.

Add Someone

Write / Read & Write is capped at 2 people — these are your two Approvers. A change one of them proposes needs the other one's sign-off before it takes effect. Read-only Viewers can be added without limit.

Working Days & Holidays

Marking a day as a Holiday only affects the expected working-hours calculation on the Dashboard's Machine & Production section — it doesn't lock anyone out or stop them logging readings on that day. If part of the factory genuinely runs on a Friday, that's fine; that day's real production still shows up as normal, it just won't count as an "expected" working day when totalling hours.

Quick Setup — Mark Every Friday

The usual weekly off day. Do this once per year instead of one Friday at a time.
